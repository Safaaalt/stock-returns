# Apple stock Data return Analyzer 
# What it is?
An interactive Jupyter Notebook tool that automatically downloads historical Apple stock data using "yfinance" to calculate daily assets return rates and volatility metrics and represent the data in a chart 
# About me 
A baccalaureat student passionate by techfin, currently learning how to merge financial data analysis workflows with Python engineering.
## features&visualization
**Data calculations: Automatically computes total tracking days , average returns , volatility risks and peak historic high/low price boundaries .
**trend chart : Renders an orange , grid-mapped timeline chart plotting exact daily asset return percentages over time.
## how to run??
1. Run 'py -m pip install -r requirements.txt' in your terminal workspace to set up all underlying library packages.
2. Launch your preferred development environment and open the 'stock_return.ipynb'notebook file to execute the code blocks natively!!
